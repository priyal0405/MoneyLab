# Money Lab: Project Notes

An educational site for young and first-time investors. It's built around one question: *what should I understand before I put my money somewhere?*

## Plan (build in this order)
1. **Investment Time Machine** (`time-machine.html`): what ₹x put into Nifty, gold or an FD in 2010 would be worth today. Animated charts, an inflation-adjusted view, static historical data we prepare ourselves.
2. **Stock & Fund Comparison** (`compare.html`): compares two funds on returns, risk and expense ratio, using a free API.
3. **RBI Policy Explainer** (`rbi-explainer.html`): turns a pasted headline into plain language about loans, savings and prices, with a Hindi option. It needs a small backend so the AI key stays out of the browser.

## Rules
- Every page says "educational, not investment advice".
- AI-generated explanations are clearly marked as possibly imperfect.

- 2026-10-29: Built the fund comparison page, called "Fund Face-Off" (`compare.html`, `js/compare.js`). It gets live NAVs from mfapi.in (free, no key, CORS allowed) and works out 1/3/5-year returns, 3-year volatility and the worst fall over 5 years, plus a ₹10,000 growth chart (1Y/3Y/5Y/Max). The expense ratio isn't in the API, so the user types it in. That figure also gives a rough estimate of fees on ₹1 lakh over 10 years at 12%. It covers mutual funds only, because free stock APIs need keys or block browser requests.
- 2026-10-29: Fixed the compare graph not loading. **Root cause:** mfapi's cached copies of `/mf/<code>` don't include the CORS header, so the browser blocked them. Fix: request `/mf/<code>?startDate=2000-01-01`, because a query string skips the cache. Also added retries. Made the page easier to use: it opens with UTI Nifty 50 Index vs Parag Parikh Flexi Cap already loaded, has one-click popular fund chips, Enter picks the first search result, the VS button swaps the funds, the expense ratio is optional, and the chart works with just one fund. Tested with a headless Chrome screenshot.
- 2026-10-29: Fixed fund search. mfapi's `/mf/search` can take over 30 seconds, so search now runs locally over `js/funds.js`. That file has 3,538 active open-ended Growth funds (Direct and Regular) built from AMFI's `NAVAll.txt` (https://portal.amfiindia.com/spages/NAVAll.txt). Rebuild it occasionally to pick up new funds. Results show a Direct/Regular tag and the category. Added a "What is an expense ratio?" explainer section, with "?" links next to the expense ratio inputs.
